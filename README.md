# 🍿 Popcorn Find - Movie Discovery App

Live Demo: [https://popcorn-find-jkra7tgsk-ragini1111s-projects.vercel.app]

## 🎯 Overview
Responsive web app to discover movies using The Movie Database (TMDB) API. Search by title, filter by genre, and view ratings. Built to practice async JavaScript and API integration.

## ✨ Features
- Real-time movie search with debouncing
- Genre-based filtering 
- Movie details: poster, rating, release date, overview
- Mobile responsive UI
- Error handling for API failures

3. Open `index.html` in browser
